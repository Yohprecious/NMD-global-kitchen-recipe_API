# The Global Kitchen API

## Tech Stack
- **Runtime:** Node.js (via tsx and vite)
- **Framework:** React (Frontend) + Express (Backend)
- **Database:** Firebase Firestore (NoSQL)
- **Configuration:** .env, firebase-applet-config.json

## Features
- **Cameroonian Digital Cookbook:** A curated collection of traditional meals like Ndolé, Poulet DG, Achu, and Koki.
- **AI Recipe Generator:** Integrated with Gemini 1.5 Flash to automatically generate authentic recipes based on meal names.
- **Responsive UI:** Clean, classic, and high-quality design for mobile and desktop.
- **Full CRUD Support:** Users can browse, search, and add new recipes to the community.
- **Master Search:** Search recipes by title or ingredients.
- **Recipe Details:** Full ingredients list, step-by-step instructions, and video player support.

## Installation & Setup
1. **Clone the repository:**
 ```bash
 git clone [your-repo-url]
 ```
2. **Install dependencies:**
 ```bash
 npm install
 ```
3. **Create a .env file in the root directory and add your API keys:**
 ```env
 GEMINI_API_KEY=your_key_here
 ```
4. **Start the server:**
 ```bash
 npm run dev
 ```
